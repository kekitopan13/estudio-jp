Ejercicios de japonés

✨ Ejercicios en uso
🔗
Match Up Ejercicio rápido de asociación para practicar pares relacionados mediante matching interactivo. Ideal para vocabulario, kanji, lecturas o conceptos que necesiten reconocimiento y memoria activa.
Requiere 2 campos.
🌱
Learning Phase Sistema de aprendizaje progresivo para vocabulario japonés que combina exposición, construcción, lectura y comprensión. Evalúa familiaridad real y refuerza palabras difíciles mediante rondas y desafíos acumulativos.
Requiere 3 campos.
🌊
Deep Recall Entrena vocabulario japonés en múltiples direcciones: lectura, escritura y significado. El ejercicio adapta repasos según tus fallos y te ayuda a consolidar palabras de forma profunda.
Requiere 3 campos.
🌀
Kanjis Confusos Ejercicio de discriminación visual para practicar kanjis similares entre sí. Agrupa familias de confusión y te obliga a distinguir significado, forma y pequeños detalles bajo presión.
Sólo funciona con kanjis confusos. Requiere 3 campos.
